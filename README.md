# Architecture Portfolio

A static architecture portfolio demo with large project photography and a hamburger category menu for filtering building typologies.

## Local preview

Serve the `website` folder with any static file server, then open the local URL in a browser.

## GitHub Pages

Production is deployed by `.github\workflows\deploy-prod.yml` to:

https://kirupa.github.io/architecture/

## Content notes

Project names and descriptions are sample portfolio content. Photography uses remote Unsplash-hosted placeholder images for demo purposes and should be replaced with owned project photography for production.
